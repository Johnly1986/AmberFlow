## 2. 每阶段的预期（可测）

### F0 预检

预期二值：探针 OK → 真站复测按 §2 F2b 预期执行；探针 403 → 复测预期**降级**为
"验证 F1c 的带类型停因路径"（这本身是 F1c 的成功判据，但不能测 F1b 对真实投票的影响，
F1b 的效果改由离线 lane A/B 佐证）。

### F1（三项并行，b 依赖 a）

| 项 | 门禁 | 预期 |
|---|---|---|
| a 接缝 | 跨步计数器场景**先行补 2–4 条**，然后 `npm run check` 全链、`verify:runtime:offline` 8/8、`verify:run-execution` golden | **平直通过 = 可观测面零变化**（平直是必要非充分——四项隐性行为：预算单位/跨步账本/守卫次序/阶梯池换代，见设计文档 §4 Step A） |
| b 身份兜底 | prompt 快照重录（diff 只落空标签行）+ 同池 A/B lane | `input ""` → `combobox[name=q]`；**爆炸半径 0**（12 停因/4 兜底/CLI 腿零重开——PM 验收 ①） |
| c 鉴权硬停 | 打桩 401/403 lane | 首次 ask 即带类型停因 + 一行修法；**整个 run 不再翻转 `rulesOnly`**；健康路径 ask 计数零漂移 |

**F1b 的走查级预期**（沿用评估文档验收）：搜索框步低置信停车/误点 ≈100% → **<20%**；
池内有身份时渲染含身份 token 比例 **≥95%**（回归 lane 可断言）。

### F2

**F2a 观测体检**：12 停因场景重放，交接证据含 `pool_size / truncated / 抽取异常计数 / 可见性摘要`
占比 **0 → 100%**（PM 验收 ②）；观测异常时**禁止**判 `low_confidence`（先重抽或扩池）。

**F2b 真站复测**（Maps 三段任务全量重跑）——预期带与不承诺项分开写：

| 段 | 预期 | 依据 |
|---|---|---|
| 第 1 段（九宫格→Maps） | 稳定复现：约 2 ask、秒级（本会话三次实测 3.9s→1.66s→1.59s） | 已稳定 |
| 第 2 段（餐厅+三筛选） | 搜索框步应通过；进入餐厅结果页预期达成；**三个筛选不承诺全过**（互斥弹层是产品事实）——成功判据是**每个失败可命名**：named precondition 或 `model_abstain{pool_size,asks}`，而非无因 `low_confidence` | F1b + F2a + 弃权出口 |
| 第 3 段（前五家评论） | 仅当第 2 段产出筛选后列表才启动；不单独设数值预期 | 依赖第 2 段 |

### F3

- **F3a 步级 done**：第 2 段的 `low_confidence` 转成**有名字的前置条件**（评估文档验收原句）；
  `verify:pilot` 增场景钉住；第 1 段 2 ask / 秒级**不得退化**（回归基线）。
- **F3b 命令行腿**：两腿跑同一套契约检查（决策记账 / `needs_value` / 危险拒绝），命令行腿
  **0 条 → 同绿**（PM 验收 ②）。

## 3. 预期管理（三条诚实声明，写进计划防止过度承诺）

1. **403 根因是权益，不是代码**（`AccessDenied.Unpurchased`）。F1c 只保证"大声失败 + 可归因"，
   **不修复访问权**——那是外部依赖（换有权限的地址/密钥，或走本地 laya 并接受 `score_kind` 差异）。
2. **`fill changed=false`（填了没提交）是动作面问题**。F1b 可能顺带缓解（Search 按钮身份可见后
   模型可投它），但**不承诺**；F2b 复测采集该数据点，若仍在，单独立项（候选形态：
   fill 后的提交手势组合，或模型对 Search 按钮的后继票）。
3. **"三个筛选全过"不是任何阶段的验收目标**。互斥弹层、评分按钮时隐时现是产品事实；
   验收目标从"跑通"改为"**每个失败可命名**"——这与评估文档的产品价值排序一致
   （跑通可落地 > 可解释 > 快）。

## 6. 一句话

先立分层（F1a）再修缺陷（F1b），让每一次修复都落在正确的层；鉴权硬停（F1c）同步并行，
把"模型不在位"变成一句话事实；观测体检（F2a）让之后的每个失败都有名字；真站复测（F2b）
只承诺"可命名"不承诺"全跑通"；步级 done（F3a）是通往完全接管的最后一块契约，
命令行腿（F3b）让三层结构有两个消费者可证。
